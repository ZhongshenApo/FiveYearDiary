# 📖 极简五年日记 (FiveYearDiary)

一款**本地优先、绝对隐私**的跨平台极简五年日记本。
由一个不懂代码的人，通过和 AI (Trae) 进行 Vibe Coding，在半小时内结对编程开发并打包完成。

## ✨ 核心理念
* **数据主权绝对安全**：所有的日记数据只保存在你自己的电脑里，完全以纯文本的 Markdown (`.md`) 格式存储。不连任何云数据库，哪怕软件没了，你的日记也永远是你的。
* **时间固定窗口**：这是一本“向前走”的实体日记本。无论你在哪一年打开，界面始终且只渲染连续的 5 个年份（例如 2026-2030）。
* **交互哲学**：
  * **过去**：只读状态，文字沉淀，只可追忆。
  * **当下**：唯一可编辑的区域，书写今天。
  * **未来**：锁定状态，留白以待。

## 🚀 如何在你的电脑上运行？

无论你是 Mac 还是 Windows，只要你有 Node.js 环境，都可以一键跑起来。

### 1. 下载源码
你可以点击右上角绿色的 `Code` 按钮 -> `Download ZIP`，然后解压到你的电脑里。
或者在终端执行：
```bash
git clone https://github.com/ZhongshenApo/FiveYearDiary.git
cd FiveYearDiary
```

### 2. 安装依赖并运行
确保你的电脑安装了 Node.js（推荐 18+ 版本）。在终端里执行以下命令：
```bash
# 一键安装所有依赖
npm install

# 一键启动桌面应用
npm run start
```

### 3. 一键打包成你自己的独立 App（可选）
如果你想把它变成一个像微信一样可以双击打开的独立软件（`.app` 或 `.exe`）：
```bash
npm run pack
```
打包完成后，去根目录的 `dist` 文件夹里，就能找到为你系统量身定制的安装包啦！

## 📂 我的日记存在哪了？
当你把项目打包成独立 App 后，为了不把你的代码文件夹弄乱，日记文件会自动保存在你电脑的 **“文稿 (Documents)”** 文件夹里。
具体路径：`你的电脑/文稿/FiveYearDiary_Data/`

如果你只是在开发模式下（`npm run start`）运行，日记会保存在源码目录的 `/data` 文件夹下。
